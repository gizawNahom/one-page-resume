# One Page Resume

A single-page portfolio for Nahom Derese Gizaw, a senior backend engineer. It presents experience, selected systems, and technical skills in a responsive layout.

## Local Development

```bash
npm install
npm run dev
```

Open `http://127.0.0.1:3000` in a browser.

## Checks

```bash
npm run lint
npm test
```

`npm test` builds the production application and runs the Playwright browser suite against an isolated local server.
